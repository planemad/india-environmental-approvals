# Glossary of Parivesh terms

Plain-language explanations of the values that appear in the **Proposal Type**, **Last Visible Status**, **Category**, **Project Category (Code)** and **Description** columns of the project tables.

The dashboard reads this file to show a tooltip when you hover over a value in the Project List. Each section heading matches a column name and each row is `Value | Meaning | Also appears as`. Variants in the last column (different capitalisation, spelling or hyphenation of the same value) share the same explanation.

> Parivesh does not publish official definitions for these labels. The explanations below are compiled from the names of the workflow stages, the EIA Notification 2006, the Forest (Conservation) Act and the CRZ Notification, so treat them as explanatory rather than legal text. Where the meaning of an abbreviation is inferred, it is marked "likely".

## Proposal Type

| Value | Meaning | Also appears as |
|---|---|---|
| New | A first-time application for a project that does not yet have this clearance. | |
| Expansion | An application to enlarge or modify a project that is already operating or already cleared. | Expanstion |
| Amendment | An application to change the terms of an existing clearance. | |
| (blank) | The proposal type was not recorded. | |

## Category

| Value | Meaning | Also appears as |
|---|---|---|
| EC | The application is for an Environmental Clearance (final permission to build or run the project). | |
| TOR | The application is for Terms of Reference, the first step before an EC for projects that need a full EIA study. | |
| CRZ | The application is for clearance under the Coastal Regulation Zone Notification, for work near the coast. | |
| OTHER | A follow-up application on an existing clearance, such as a transfer, amendment, validity extension, corrigendum or surrender. | |
| (blank) | Usually a forest or wildlife clearance proposal, which has no EC/ToR category. | |

## Project Category (Code)

| Value | Meaning | Also appears as |
|---|---|---|
| A | Largest projects (for example large mines, power plants and industries). Reviewed by the central EAC and cleared by MoEFCC. Needs a full EIA study. | |
| B1 | Medium-impact projects. Reviewed by the state SEAC and cleared by SEIAA. Needs an EIA study. | |
| B2 | Lower-impact projects. Cleared by SEIAA without a full EIA study. Most small mines and buildings fall here. | |
| NONMIND | Non-mining projects, a label used by some state records. | |
| MIND | Mining projects, a label used by some state records. | |
| CRZ | A project handled under the Coastal Regulation Zone Notification. | |
| Transfer of CRZ Clearance | An application to transfer an existing CRZ clearance to a new holder. | |
| 7(e) | A coastal project category recorded as a CRZ clause reference. | |
| Ship Building Yard | A coastal shipbuilding yard project. | |
| Storage terminal | A coastal storage terminal project. | |
| Pipeline | A pipeline project in a coastal area. | |
| (blank) | No project category recorded, common for forest, wildlife and CRZ proposals. | |
